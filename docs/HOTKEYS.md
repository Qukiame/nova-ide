# Горячие клавиши Nova IDE

## Файл

| Клавиша | Действие |
|---|---|
| `Ctrl+N` | Создать новый файл |
| `Ctrl+O` | Открыть файл (диалог выбора) |
| `Ctrl+S` | Сохранить текущий файл |
| `Ctrl+Shift+S` | Сохранить как… (диалог выбора пути) |
| `Ctrl+Shift+O` | Открыть папку проекта (файловое дерево) |
| `Ctrl+W` | Закрыть текущую вкладку (с подтверждением, если есть изменения) |
| `Ctrl+Q` | Выход из приложения |

## Правка

| Клавиша | Действие |
|---|---|
| `Ctrl+Z` | Отменить |
| `Ctrl+Y` / `Ctrl+Shift+Z` | Повторить |
| `Ctrl+X` | Вырезать |
| `Ctrl+C` | Копировать |
| `Ctrl+V` | Вставить |
| `Ctrl+F` | Открыть панель «Найти / Заменить» |

### В панели поиска

| Клавиша | Действие |
|---|---|
| `Enter` (в поле «Найти») | Следующее совпадение |
| Кнопка «Найти» | Следующее совпадение (циклически) |
| Кнопка «Заменить» | Заменить текущее + перейти к следующему |
| Кнопка «Все» | Заменить все совпадения (лимит 100 000) |
| `×` | Закрыть панель |

## Навигация по вкладкам

| Клавиша | Действие |
|---|---|
| `Ctrl+Tab` | Следующая вкладка |
| `Ctrl+Shift+Tab` | Предыдущая вкладка |
| Двойной клик по вкладке | Закрыть (если вкладка с `×`) |
| Перетаскивание вкладки | Изменить порядок |

## Запуск кода

| Клавиша | Действие |
|---|---|
| `F5` | Запустить текущий файл (сохранение автоматически) |

Поддерживаемые интерпретаторы:

| Расширение | Команда |
|---|---|
| `.py` | `python <file>` (использует интерпретатор, которым запущена IDE) |
| `.js` / `.mjs` | `node <file>` |
| `.sh` / `.bash` | `bash <file>` |

Вывод (stdout + stderr) открывается в новой вкладке «▶ Вывод».
Таймаут выполнения — 30 секунд.

## Вид

| Клавиша | Действие |
|---|---|
| `Ctrl` + `+` | Увеличить шрифт редактора (6–36 pt) |
| `Ctrl` + `-` | Уменьшить шрифт редактора |

## Помощь

| Клавиша | Действие |
|---|---|
| `F1` | О программе (версия, возможности, платформа) |

## Файловое дерево

| Действие | Эффект |
|---|---|
| Двойной клик по файлу | Открыть в новой вкладке |
| Одинарный клик по папке | Развернуть/свернуть |
| Сортировка | По имени, А→Я |

## Советы

- Текущий номер строки в области номеров подсвечивается акцентным
  синим цветом `#58a6ff`
- В заголовке вкладки `●` перед именем означает несохранённые изменения
- При попытке закрыть изменённый файл будет предложено сохранить
- При запуске `.py`-файла он сначала сохраняется (если изменён), потом
  выполняется тем же интерпретатором Python, который запустил IDE —
  значит, все установленные пакеты доступны
