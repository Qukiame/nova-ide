# Этикет контрибьюшена в Nova IDE

Проект Nova IDE приветствует участников любого уровня подготовки.
Чтобы сообщество было комфортным для всех, придерживайтесь простых правил:

## Обещания

- **Будьте дружелюбны и терпимы.** За проектом сидят живые люди с разными
  уровнями опыта, культурным фоном и количеством свободного времени.
- **Уважайте чужое время.** Перед тем как задать вопрос, проверьте Issues и
  README — возможно, ответ уже есть.
- **Принимайте конструктивную критику.** Замечания к коду — не замечания к
  вам лично.
- **Фокусируйтесь на том, что лучше для проекта.** А не на том, «как
  принято в моём фреймворке».

## Недопустимо

- Оскорбления, угрозы, травля.
- Дискриминация по полу, ориентации, национальности, религии, возрасту,
  инвалидности или любому другому признаку.
- Сексуализированный контекст в коде, коммитах, issue и PR.
- Публичное разглашение личных данных участников без их согласия.

## Если вы столкнулись с нарушением

Свяжитесь с мейнтейнером через личные сообщения на GitHub.
Жалобы рассматриваются конфиденциально.

## Сфера действия

Эти правила действуют во всех пространствах проекта: issue, PR,
обсуждения, коммиты, комментарии — а также в любых публичных
пространствах, где представитель проекта выступает от его имени.
